# GrowthOS Frontend Storefront

The primary Next.js E-Commerce Storefront (Domino's Experience) instrumented with GrowthOS Behavioral SDK is located in [`research/frontend/`](file:///home/mihir/Codes/internship/GrowthOS/research/frontend).

### Quick Start
```bash
cd research/frontend
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the storefront.
